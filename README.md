# Portfolio

Static portfolio site. The HTML pages remain at the repository root as the site entry points.

## Project structure

- `index.html`, `headroom.html`, `paynora.html` — homepage and case studies
- `styles/` — shared and page-specific stylesheets
- `scripts/` — shared browser interactions
- `assets/images/profile/` — profile photography
- `assets/images/portfolio/` — homepage portfolio imagery
- `assets/images/headroom/` — Headroom project imagery and research boards
- `assets/images/paynora/` — PayNora project imagery and research boards
- `assets/documents/professional/` — resume
- `assets/documents/headroom/` — Headroom project documents
- `assets/documents/paynora/` — PayNora project documents
